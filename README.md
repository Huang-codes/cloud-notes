## ⚠️ 甲骨文云（OCI）关键避坑：双重防火墙机制

甲骨文云有两道防火墙，**必须两道都放行**才能从外网访问端口 8000：
1. **甲骨文云 Web 控制台的安全列表 (Security List)**（外层）
2. **虚拟机 Linux 系统自带的 iptables / firewalld 防火墙**（内层，甲骨文云系统镜像默认带有非常严格的入站拦截规则）

## 🚀 部署指南（三步搞定）

### 第一步：在甲骨文云 (OCI) 控制台放行 8000 端口

1. 登录 [Oracle Cloud 控制台](https://cloud.oracle.com/)。
2. 左上角菜单选择 **计算 (Compute)** -> **实例 (Instances)**，点击你的云服务器实例。
3. 在实例详情页中，点击 **子网 (Subnet)** 的链接（进入所属的虚拟云网络 VCN）。
4. 在子网页面中，点击 **默认安全列表 (Default Security List for ...)**。
5. 点击 **添加入站规则 (Add Ingress Rules)**：
   * **无状态 (Stateless)**：不勾选
   * **源类型 (Source Type)**：`CIDR`
   * **源 CIDR (Source CIDR)**：`0.0.0.0/0`
   * **IP 协议 (IP Protocol)**：`TCP`
   * **目标端口范围 (Destination Port Range)**：`8000`
   * **说明 (Description)**：`Cloud Notes API`
6. 点击 **添加入站规则 (Add Ingress Rules)** 保存。

---

### 第二步：在甲骨文云 VM 上一键部署后端

SSH 连接到你的甲骨文云 Linux 实例，上传或克隆 `backend` 文件夹，然后运行：

```bash
cd backend
chmod +x deploy.sh && ./deploy.sh
```

> 💡 **特别说明**：`deploy.sh` 已经内嵌了针对甲骨文云系统防火墙（`iptables` / `ufw` / `firewalld`）的自动放行代码，无需手动一条条排查复杂的 Linux 防火墙规则！

**验证服务**：
在手机或电脑浏览器中直接访问 `http://<你的甲骨文云公网IP>:8000`，能直接打开精美的记事本网页端并正常使用，说明后端部署成功！

---

### 第三步：获取与安装 Android 客户端 (.apk)

#### 途径 A：使用 GitHub Actions 云端自动打包（最推荐，零配置）
1. 将本项目推送到你自己的 GitHub 仓库。
2. GitHub 会自动触发 `.github/workflows/build-apk.yml` 流水线。
3. 等待约 2-3 分钟，在仓库页面的 **Actions** 标签页中找到最新运行的构建任务。
4. 在页面底部的 **Artifacts (构建产物)** 直接下载 `CloudNotes-Debug-APK.zip`。
5. 解压后将 `app-debug.apk` 发送到安卓手机上直接安装即可！

#### 途径 B：使用 Android Studio 本地打包
1. 打开电脑上的 **Android Studio**，选择 `Open` 并选择本项目中的 `android` 目录。
2. 等待 Gradle 同步完成。
3. 点击顶部菜单栏 **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**。
4. 构建完成后点击右下角 `locate` 找到生成的 APK 文件传输至手机安装。

---

## 📱 手机 App 配置与使用

1. 打开安装好的 **云笔记** App。
2. 首次进入请点击右上角 **设置图标 (⚙️)**：
   * **服务器地址**：填入 `http://<你的甲骨文云公网IP>:8000`
   * **访问密钥 (Token)**：填入与后端一致的 Token（默认是 `cloud-notes-secret`）
3. 点击 **“测试连接”** 按钮：
   * 若提示“连接成功”，点击 **“保存”**。
4. 返回主页面即可随时新建笔记、置顶、分类打标、搜索和云端实时同步！

---

## 🔒 生产环境安全建议

- **修改默认密钥**：在 `backend/docker-compose.yml` 或 `deploy.sh` 中将 `API_TOKEN` 修改为你自己的密码字符串。
- **配置域名与 HTTPS**：如需使用标准 443 端口与 SSL 证书，可在甲骨文云实例上安装 Nginx 反向代理，并使用 Certbot 申请免费 HTTPS 证书。

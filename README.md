# 🍊 橙子笔记 (Orange Notes)

一套现代、优雅、高隐私的个人专属私有云笔记全栈解决方案。

---

## 🌟 核心特性

- 🍊 **专属品牌与现代设计**：暖橙色系视觉，全端深度适配 **深色模式 (Dark Theme)**。
- 🔐 **私密安全与账号体系**：支持邮箱/用户名与密码注册登录（PBKDF2-HMAC-SHA256 哈希加密 + JWT 鉴权），告别繁琐公网 IP 和密钥输入；支持 **指纹/面容生物识别应用锁**。
- ⚡ **自动保存 (Auto-save)**：编辑器内置输入防抖自动存 + 页面离开强制保存，告别手动点击。
- 📝 **待办清单与富文本**：支持可打勾的待办任务清单 `[ ]`，加粗、斜体、各级标题与超链接语法。
- 📸 **图片与多媒体附件**：支持调用手机相机拍照及相册图片直接上传云端附件。
- 🌐 **离线缓存与自动同步**：手机端内置本地 SQLite 离线缓存，**断网秒开可读写**，恢复网络静默同步至云端。
- 🗑️ **防误删回收站**：软删除机制，误删笔记随时一键还原或彻底清空。

---

## 🚀 服务端快速部署

```bash
cd backend
chmod +x deploy.sh && ./deploy.sh
```

部署完成后，在浏览器中访问 `http://<你的服务器IP>:8000` 即可直接使用自适应 Web 客户端！

---

## 📱 Android 手机端构建与安装

本项目内置 GitHub Actions 自动化持续集成：
1. 代码推送到 GitHub 仓库主分支后，GitHub Actions 会全自动编译出最新的 `app-debug.apk`。
2. 在仓库的 **Actions** 标签页中找到最新构建任务，在 **Artifacts** 处直接下载并安装到安卓手机即可。
